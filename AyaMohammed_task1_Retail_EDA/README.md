📊 Retail Sales Exploratory Data Analysis (EDA)
This project is part of my Data Analytics Internship at Oasis Infobyte (Task 1). The objective is to perform Exploratory Data Analysis (EDA) on a retail sales dataset to uncover actionable business insights, customer purchasing behaviors, and sales trends.

🛠️ Tools & Technologies Used
Python
Pandas (Data Manipulation & Aggregation)
Matplotlib & Seaborn (Data Visualization)
Jupyter Notebook / VS Code
📂 Dataset Overview
The dataset (retail_sales_dataset.csv) contains 1,000 transaction records with zero missing values across key attributes including Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

🔍 Key Analytical Insights
Top Performing Categories: Electronics led total revenue ($156,905), closely followed by Clothing ($155,580) and Beauty ($143,515).
Customer Demographics (Gender): Female customers generated slightly higher total sales ($232,840) compared to male customers ($223,160).
Age & Spending Patterns: Customer ages are well-distributed between 18 and 64, while the majority of individual transactions are concentrated below $250.
Sales Trend Over Time: Monthly trend analysis revealed a significant sales peak in May 2023, alongside strong seasonal fluctuations throughout the year.
🚀 How to Run
Clone this repository or download the .ipynb and .csv files.
Ensure pandas, matplotlib, and seaborn are installed in your Python environment.
Open Oasis_Infobyte_Task1.ipynb in Jupyter Notebook or VS Code and run all cells.
